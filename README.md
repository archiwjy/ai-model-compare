# AI 모델 성능비교판

두 평가기관(**Epoch AI**, **Artificial Analysis**)의 점수를 합쳐
AI 모델의 **추론 등급별 종합 성능**과 **비용**을 한 장의 지도(산점도)로 비교하는 화면입니다.

- 점 하나 = 모델 하나의 추론 등급 하나 (예: Claude Opus 5.5 · xhigh)
- 위로 갈수록 똑똑하고, 왼쪽으로 갈수록 쌉니다
- **보라 계단(가성비 경계선)** 위의 모델을 고르면 돈을 낭비하지 않습니다
- 6시간마다 GitHub 가 최신 데이터를 받아 자동으로 갱신합니다

> 실제 화면 주소는 비밀 링크라 이 저장소에는 적혀 있지 않습니다. 실행 기록에서는 가려지고(add-mask), 사이트 묶음은 배포 직후(실패해도) 지워지며, 페이지는 바깥 사이트에 주소를 보내지 않습니다(referrer 없음).

## 어떻게 돌아가나요

```
6시간마다 (GitHub Actions · .github/workflows/update.yml)
  ① 소스코드/collect.py     기관 데이터 받기 → 종합 점수·비용 계산 → 웹/data.js
  ② 소스코드/build_site.py  화면 파일 묶기 (파일마다 내용 지문 ?v= 를 붙여 옛 파일이 남지 않게)
  ③ 소스코드/auto_check.py  문제가 있으면 GitHub 이슈로 알림, 해결되면 스스로 닫음
  ④ GitHub Pages 에 올리기
```

**튼튼하게 만든 부분**

| 상황 | 동작 |
|---|---|
| 한 기관 데이터를 못 받음 | 반쪽 데이터 대신 **마지막 정상 데이터**를 계속 보여 줌 (7일까지) |
| 기관 응답에 이상한 값이 섞임 | 그 줄만 건너뛰고 나머지는 받음 (건너뛴 개수는 실행 기록에) |
| 받은 파일이 깨짐(점검 중 화면 등) | 저장해 둔 정상 원본을 덮어쓰지 않음 |
| 비용 기준(LiveBench)이 빠진 날 | 지난번 환산 비율로 **같은 비용 단위**를 유지 |
| 화면 데이터가 깨졌거나 그래프 도구를 못 불러옴 | 하얀 화면 대신 **한국어 안내** + 새로고침 버튼 |
| 인터넷이 끊김 (설치한 앱) | 마지막으로 본 화면을 그대로 보여 줌 |

## 폴더 구조

```
소스코드/
├─ collect.py        데이터 수집기 (실행 순서의 시작)
├─ sources.py        기관별 데이터 받기 (Epoch · AA · LiveBench · OpenRouter)
├─ names.py          출처마다 다른 모델 이름 → (기본이름, 추론 등급) 으로 통일
├─ combine.py        종합 점수(문항반응이론) · 비용 환산 계산
├─ 이름_보정표.json   자동으로 못 맞추는 이름을 손으로 적는 표
├─ build_site.py     사이트 파일 묶기
├─ auto_check.py     자동 점검 (GitHub 이슈 알림)
├─ server.py         이 컴퓨터에서 볼 때의 도우미 (127.0.0.1:8770)
├─ open_dashboard.py '성능비교판_열기' 가 실행하는 파일
├─ publish_site.py   코드 올리기 (전체 검사를 통과해야 올림)
├─ make_icons.py     앱 아이콘 다시 그리기
├─ 웹/               화면 (index.html · app.js · core.js · style.css · sw.js …)
├─ 테스트/           자동 시험 (파이썬 · 화면 계산 · 크롬 화면 시험)
└─ 검사/             전체 검사 (검사.py) 와 규칙 파일
```

## 전체 검사 (버튼 하나)

```bash
python 소스코드/검사/검사.py
```

처음 한 번은 검사 도구(ruff · mypy · ESLint · TypeScript)를 저장소 밖 폴더에 자동으로 설치합니다 (1~2분). 필요한 것: Python 3.12 이상 · Node.js 22 이상 · 크롬.

| 단계 | 내용 |
|---|---|
| 파이썬 버그·문법 검사 | ruff |
| 파이썬 타입 검사 | mypy (윈도우·리눅스 두 번 — GitHub 은 리눅스에서 돎) |
| 파이썬 시험 | 수집 · 계산 · 도우미 서버 · 사이트 묶기 · 자동 점검 · 올리기 |
| 화면 코드 버그·문법 검사 | ESLint (경고 0개여야 통과) |
| 화면 코드 타입 검사 | TypeScript (계산 모듈은 가장 엄격하게) |
| 화면 계산·저장 시험 | 추천 규칙 · 검색 · 경계선 · 데이터 정리 · 서비스 워커 |
| 화면 자동 시험 | 크롬으로 실제 화면을 PC·낮은 노트북·태블릿·휴대폰(320px 포함)·가로·어둡게, 키보드만으로, 망가진 데이터·10배 큰 데이터·시작 뒤 오류까지 |

- `--빠르게` : 크롬 화면 시험만 빼고 (10초 안팎)
- `--사진` : 화면 시험 때 주요 화면을 사진으로도 저장
- `--단계 이름` : 한 단계만 (예: `--단계 파이썬`). 이름을 잘못 치면 쓸 수 있는 이름을 알려 주고 멈춤
- 코드를 올릴 때마다 GitHub 에서도 같은 검사가 자동으로 돕니다 (`.github/workflows/check.yml`)

이름 정리·계산 코드를 고쳤다면 **같은 원본으로 결과가 어떻게 바뀌는지** 비교할 수 있습니다:

```bash
python 소스코드/검사/데이터_비교.py 기준   # 고치기 전에
python 소스코드/검사/데이터_비교.py        # 고친 뒤 → 모델 추가·삭제·이름·회사·점수·비용 변화
```

## 비밀 값 (GitHub 설정 → Secrets)

| 이름 | 용도 |
|---|---|
| `AA_API_KEY` | Artificial Analysis 무료 API 키 (필수) |
| `SITE_SECRET` | 화면 주소(비밀 폴더 이름)를 만드는 값. 없으면 AA 키로 만듦. 넣거나 바꾸면 **주소가 바뀝니다** — 예전 실행 기록에 주소가 남아 있다면 새 값을 넣어 주소를 바꾸는 것을 권해요 (즐겨찾기·공유한 주소도 새로 바꿔야 함) |
