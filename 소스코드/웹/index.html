점수 출처와 비중

한 곳의 말만 믿지 않도록 여러 기관의 점수를 합칩니다. 비중은 기관마다 다른 기관들의 합의와 얼마나 잘 맞는지로 자동 계산되며, 아래에서 직접 조절할 수도 있습니다.

어떻게 계산하나요?

종합 성능 점수
  1. Epoch AI 방식 능력치 — 벤치마크마다 "얼마나 어려운지"와 "실력 차이를 얼마나 잘 가려내는지"가 정해져 있습니다. 모델이 받은 점수들을 가장 잘 설명하는 능력치 하나를 찾습니다. 쉬운 시험만 본 모델이 부풀려지지 않습니다. 눈금은 GPT-5 = 150, Claude 3.5 Sonnet = 130입니다.
  2. 다른 기관 점수를 같은 눈금으로 — Artificial Analysis, LiveBench, LMArena 점수를, 양쪽에 다 있는 최신 모델들을 기준으로 같은 눈금에 맞춥니다.
  3. 비중은 데이터가 결정 — 다른 기관들과 크게 어긋나는 기관일수록 비중이 줄어듭니다. LMArena는 사람의 선호 투표라 말투·형식의 영향이 있어서 기본 비중을 절반으로 둡니다.
  4. 같은 모델 안에서 빈칸 채우기 — 어떤 기관이 한 등급만 평가했다면, 다른 기관들이 본 "등급 간 차이"만큼 옮겨서 나머지 등급 값을 추정합니다. 그래야 한 모델의 점들이 같은 기준으로 비교됩니다. (표와 상세에서 추정으로 표시)
  5. ± 범위와 신뢰도 — 평가한 기관 수와 벤치마크 수가 적거나 기관끼리 의견이 다를수록 범위가 넓어집니다. 점수 차이가 이 범위보다 작으면 사실상 비슷한 것입니다.
문제당 비용

같은 모델은 추론 등급을 올려도 "글자당 가격"은 같지만, 더 오래 생각하느라 글자를 훨씬 많이 씁니다. 그래서 가격표가 아니라 실제로 문제를 풀 때 든 비용을 씁니다.

  • 측정: LiveBench·Artificial Analysis·DeepSWE·CursorBench·ARC-AGI 등에서 실제 기록된 비용을 LiveBench 문제 1개 기준으로 환산해 평균낸 값
  • 등급 환산: 같은 모델의 다른 등급 비용에서, 데이터로 추정한 "등급별 비용 배율"로 계산 ()
  • 가격 추정: 측정 기록이 전혀 없어 가격표로 대략 추정 — 그래프에서 속이 빈 점

맞힌 문제당 비용 = 문제당 비용 ÷ 정답률. 싸도 자주 틀리는 모델은 다시 시켜야 하니 실제로는 더 비싸다는 점을 반영합니다.

정답률은 조절 줄의 작업 난이도에 따라 계산합니다. 종합 점수가 Epoch 방식 능력치라서 "이 난이도 시험에서 몇 %를 맞힐지"를 바로 계산할 수 있습니다. 쉬움(간단한 질문·번역) → 보통(일반 업무·대학원 수준) → 어려움(어려운 코딩·전문 분석) → 매우 어려움(최고난도 연구·에이전트). 어려울수록 약한 모델의 정답률이 크게 떨어져 맞힌 문제당 비용 차이가 벌어집니다.

어려운 일은 모델이 더 오래 생각해 문제당 비용 자체도 늘지만, 이 부분은 자료가 부족해 반영하지 않았습니다 (난이도는 정답률에만 반영).

가격은 각 회사의 공식 API 정가 기준입니다. 할인·캐시·구독 요금은 반영하지 않습니다.

가성비 경계선과 추천

가성비 경계선(점선)은 "이 비용으로 이보다 좋은 모델은 없다"는 점들을 이은 선입니다. 선 위의 모델을 고르면 돈을 낭비하지 않습니다.

가성비 추천은 최고 점수의 오차 범위(최소 3점) 안에 드는 것 중 가장 싼 것입니다. 그 정도 차이는 사실상 같은 수준이기 때문입니다. 표의 가성비 칸은 비용이 10배 늘 때 점수가 얼마나 오르는지를 기준으로 한 상대 점수입니다.
